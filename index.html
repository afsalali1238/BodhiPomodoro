# 2. Enter prototype directory & install dependencies

cd BodhiPomodoro/prototype && npm install

# 3. Launch the desktop pet in development mode

npm start

# 4. Run automated test suite (36/36 tests)

npm test

# 5. Build your own Windows NSIS installer .exe

npm run dist:win

Installation & Clean Uninstallation

Full support for standard Windows application management.

📥 How to Install

  1. Download Bodhi Pomodoro Setup 0.3.0.exe using the download button above.
  2. Double-click the installer to start the setup wizard.
  3. Choose your preferred install directory (or leave default).
  4. Click Install. Desktop & Start Menu shortcuts are created automatically.

⚠️ Windows SmartScreen Notice

  1. Because this is an independent open-source release without an expensive ($400/yr) corporate certificate, Windows may show: "Windows protected your PC".
  2. Click "More info".
  3. Click "Run anyway".
  4. This is standard for all open-source Windows tools.

🗑️ How to Uninstall Cleanly

  1. Open Windows Settings (or press Win + I).
  2. Navigate to Apps > Installed apps (or Control Panel).
  3. Find Bodhi Pomodoro in the list.
  4. Click the three dots (...) and select Uninstall.
  5. The app, executables, and all shortcuts are completely removed.
💡
Need a portable version without installation? You can run npm run dist:portable to build a standalone single .exe that runs directly without installing anything.
