Installation & Uninstallation

Simple, standard Windows application management.

📥 How to Install

  1. Download the Bodhi Pomodoro Setup 0.3.0.exe installer above.
  2. Double-click the installer to launch the setup wizard.
  3. Choose your preferred install folder (or leave default).
  4. Click Install. Desktop and Start Menu shortcuts will be created automatically.

⚠️ Windows SmartScreen Notice

  1. Because this is an independent open-source app without an expensive commercial certificate, Windows Defender SmartScreen may display: "Windows protected your PC".
  2. Simply click "More info".
  3. Click "Run anyway".
  4. This is standard for all indie desktop apps!

🗑️ How to Uninstall

  1. Open Windows Settings (or press Win + I).
  2. Navigate to Apps > Installed apps (or Control Panel > Programs).
  3. Search for Bodhi Pomodoro in the list.
  4. Click the three dots (...) and select Uninstall.
  5. The app and all its shortcuts will be cleanly removed from your PC.
