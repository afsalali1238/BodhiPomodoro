# Bodhi Pomodoro — Buddha desktop pet

## What's in this folder

| Path | What it is |
| --- | --- |
| `BUILD-HANDOFF.md` | Current plan you build from |
| `prototype/` | v0.3 app: timer, tasks, break activities, away detection, lasers, meeting hide, tree growth, daily report |

## Run

In `prototype/`: `npm install`, `npm test`, `npm start`. Tray ▸ **Take Bodhi for a walk** runs a 2-minute demo.

## Start a session

Click the pet or press `Ctrl+Alt+P` → **Start session…**

- Choose time: preset buttons (15/25/50/90 min) or custom
- Choose apps: type app names (one per line) to block; lasers fire on unlisted apps
- Leave empty to block all apps
- Lasers fire when you switch to a blocked app during focus; they stop when you return to your chosen apps

## Shortcuts

`Ctrl+Alt+P` start/pause · `Ctrl+Alt+S` skip · `Ctrl+Alt+T` tasks (Tasks tab) · `Ctrl+Alt+R` daily report
